# AI Resume Analyzer

A Python and Google Colab project that extracts text from PDF resumes and uses Google Gemini to generate an ATS-style score and feedback.

## Features

- PDF text extraction with PyPDF2
- AI-generated summary, strengths, and improvement suggestions
- API key stored securely in Colab Secrets

## Run It

Open `Ai_Resume_Analyzer.ipynb` in Google Colab, add your Gemini API key to Colab Secrets, and run the cells.
